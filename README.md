## 📱 iPhone'ga o'rnatish
Sahifani iPhone'da **Safari**'da oching → **Ulashish** → **"Bosh ekranga qo'shish"**.
O'yin bosh ekranda o'z belgisi bilan paydo bo'ladi va to'liq ekranda ochiladi.

## 🎮 O'yinlar

### [Neon Yuguruvchi](neon-runner/index.html)
Rangli, cheksiz yuguruvchi o'yin: to'siqlardan sakrang, dronlar ostidan engashing va yulduzlarni yig'ing.

- **Space / ↑** — sakrash (havoda yana bosilsa — ikki karra sakrash)
- **↓** — engashish (havoda bosilsa — tez tushish)
- **M** — ovozni o'chirish/yoqish
- **Telefonda:** ekranning o'ng tomoni — sakrash, chap tomoni — engashish

Xususiyatlari: kun → shom → tun almashinuvi, tezlik asta-sekin oshadi, rekord saqlanadi, zarracha effektlari va ovozlar.

**O'ynash:** `neon-runner/index.html` faylini brauzerda oching — hech narsa o'rnatish shart emas.

### [Rang Jangi](rang-jangi/index.html) — YouTube Shorts uchun
Vertikal (9:16) simulyatsiya: to'rtta rangli shar maydonni bo'yash uchun kurashadi, oxirida g'olib e'lon qilinadi.
Ekranni yozib olib, Shorts sifatida joylash mumkin. Tomoshabinlardan izohda g'olibni taxmin qilishni so'rang.

- **Tugmalar:** qayta boshlash, tezlik (1×/2×/3×), vaqt (30/60/90 s), ovoz, avto-takror
- **R** — qayta boshlash
