# Rangli Jo'ja 🐤

Shirinliklar olamida yuguradigan jo'ja haqidagi rangli o'yin. Telefonda (iPhone, Android) va kompyuterda ishlaydi.

**O'ynash:** https://aliyevshub.github.io/public-games/

## Boshqaruv
- **Ekranga teging** (yoki `Space` / `↑`) — sakrash
- **Uzoqroq bosib turing** — balandroq sakraydi
- **Havoda yana teging** — ikki karra sakrash
- Chap yuqoridagi tugma — ovozni o'chirish/yoqish

Lolipop va konfet bloklaridan sakrab o'ting, konfetlarni yig'ing (+10 ochko). Tezlik asta-sekin oshadi, rekord saqlanib qoladi.

## iPhone'ga o'rnatish
1. Havolani **Safari**'da oching.
2. **Ulashish** tugmasini bosing.
3. **"Bosh ekranga qo'shish"** ni tanlang — o'yin ilova kabi to'liq ekranda ochiladi.
